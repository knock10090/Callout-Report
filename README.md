# Callout Report — SERT V2

Modern OD green / coyote brown Android PWA with SERT insignia.

## Publish to GitHub Pages
1. Create a **private test repository** if possible, then upload the **contents** of this folder into its root.
2. In repository Settings → Pages, choose **Deploy from a branch**, main / root, and save. Note: GitHub Pages websites are publicly accessible even when the repository is private on many plans. **Do not enter actual incident information on a public deployment without department authorization.**
3. Visit the Pages HTTPS URL in Chrome on Android. Choose Add to Home Screen / Install app.
4. Test with fictional data, Save Word, and compare output with the approved blank template in Word. Share / Outlook uses the Android share sheet when supported, otherwise saves the DOCX.

## Important
- This prototype stores drafts in browser localStorage, which is not app-encrypted. Do not use operational data before approval and security review.
- Word export modifies a copy of the included original template.docx in-browser. It is **not yet verified pixel-identical** with the department template after population. Long text may cause a second page.
- Do not upload the ZIP itself to GitHub Pages; upload its extracted contents.
- If an older version is cached, close/reopen the app or clear site data, then reinstall the home screen shortcut.
